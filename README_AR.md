# SHAMIKH LIFE — Android MVP 1.0

تطبيق أندرويد عربي لإدارة الأهداف والمهام اليومية والتذكيرات، بواجهة داكنة ولمسات ذهبية.

## الموجود في النسخة الأولية
- لوحة قيادة يومية مع نسبة إنجاز المهام.
- إضافة المهام مع وقت تذكير محلي.
- حفظ المهام والأهداف على الجهاز باستخدام SharedPreferences.
- أهداف يومية/أسبوعية/شهرية/سنوية/طويلة الأمد.
- شاشة متابعة أولية للعبادات والأذكار.
- هيكل أقسام للعادات، التعلم، المشاريع، الأموال، الوقت، التركيز، اليوميات، التقارير ولوحة الرؤية.
- إشعارات محلية للمهام المجدولة.

## فتح المشروع وبناء APK
1. انسخ مجلد `ShamikhLife` إلى حاسوب عليه Android Studio حديث.
2. افتح المجلد في Android Studio وانتظر Gradle Sync.
3. اختر Build > Build Bundle(s) / APK(s) > Build APK(s).
4. ملف APK الناتج يظهر عادة في `app/build/outputs/apk/debug/app-debug.apk`.

## صلاحيات مهمة على الهاتف
- اسمح بإشعارات التطبيق.
- اسمح بالمنبهات الدقيقة إذا طلبها النظام؛ بعض هواتف Xiaomi تحتاج أيضاً إلى السماح بالتشغيل التلقائي وعدم تقييد البطارية حتى تصل التنبيهات في وقتها.

## ملاحظات الإصدار
هذه نسخة MVP أولية وليست الإصدار النهائي. أقسام العادات والمال والمشاريع والتقارير ظاهرة كهيكل واجهة وتحتاج استكمال منطقها في الإصدارات التالية. الأذكار الحالية عناوين تنظيمية وليست نصوص أذكار موثقة بعد. لا تعتمد على التطبيق وحده للمنبهات الحرجة قبل اختبارها على جهازك.

## بناء APK دون حاسوب (عبر GitHub Actions)
يتضمن المشروع سير عمل آلياً في `.github/workflows/build-apk.yml`. بعد رفع ملفات المشروع إلى مستودع GitHub وتفعيل Actions، يمكن تشغيل `Build SHAMIKH LIFE APK` من تبويب Actions، ثم تنزيل ملف `SHAMIKH-LIFE-debug-apk` من Artifacts. هذه العملية تتطلب حساب GitHub واتصال إنترنت، ولا تعني أن APK جاهز ضمن الملف المضغوط حالياً.
